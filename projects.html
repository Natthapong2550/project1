OUR PROJECTS

โครงงานอิเล็กทรอนิกส์

นักเรียนสามารถนำความรู้จากการเรียน มาประยุกต์ใช้ในการสร้างโครงงาน และนวัตกรรมด้านอิเล็กทรอนิกส์

การทำโครงงานช่วยให้นักเรียนได้ฝึก การวางแผน การออกแบบ การเขียนโปรแกรม การแก้ไขปัญหา และการทำงานเป็นทีม

FEATURED PROJECTS

IoT

ระบบเปิด-ปิดไฟอัตโนมัติ

ระบบควบคุมไฟผ่านโทรศัพท์มือถือ โดยใช้ไมโครคอนโทรลเลอร์และ Wi-Fi

ESP8266 Wi-Fi IoT
SENSOR

ระบบวัดอุณหภูมิ

Arduino DHT22 LCD
AUTOMATION

ระบบรดน้ำต้นไม้อัตโนมัติ

Arduino Sensor Relay
ROBOTICS

ระบบตรวจจับระยะทาง

Arduino HC-SR04 LED
BLUETOOTH

ระบบควบคุมอุปกรณ์อิเล็กทรอนิกส์ ผ่านโทรศัพท์มือถือด้วย Bluetooth

Arduino HC-05 Bluetooth
SECURITY

ระบบตรวจจับควัน

Arduino MQ-2 Buzzer

PROJECT PROCESS

ขั้นตอนการทำโครงงาน

01

คิดหัวข้อ

ศึกษาปัญหาและเลือกหัวข้อ ที่ต้องการพัฒนา

02

ออกแบบ

วางแผนระบบ ออกแบบวงจร และเลือกอุปกรณ์

03

สร้างต้นแบบ

ประกอบวงจรและเขียนโปรแกรม เพื่อสร้างต้นแบบ

04

ทดสอบ

ทดลองระบบและแก้ไขข้อผิดพลาด ที่เกิดขึ้น

05

นำเสนอ

นำเสนอผลงานและอธิบาย หลักการทำงานของโครงงาน
